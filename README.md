# tinyroof.github.io

Trang giới thiệu và chính sách quyền riêng tư cho các ứng dụng.

```
index.html                    trang chung, liệt kê ứng dụng
lich-nha-minh/index.html      trang ứng dụng, dùng làm địa chỉ hỗ trợ
lich-nha-minh/privacy.html    chính sách quyền riêng tư
```

Thêm ứng dụng mới: tạo thư mục cùng cấp rồi thêm một mục vào `index.html`.
